| Overall width | 1,754 mm | Tesla Cybercab Rider Guide, Dimensions and Specifications: https://www.tesla.com/robotaxi/riderguides/cybercab/en_us/GUID-3229BCDF-16D8-447B-BCED-77E3E067AFBB.html |
| Overall height | 1,408 mm | same |
| Ground clearance | 144 mm | same |
| Step-in height | 419 mm (414 mm in PDF edition) | same |
| Length | 4,350 mm (third party) | encyCARpedia: https://www.encycarpedia.com/tesla/26-cybercab-coupe |
| Wheelbase | 2,635 mm (third party) | encyCARpedia, same page |
